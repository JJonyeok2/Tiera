# Tiera

**AI 모델의 로튼토마토.**

👉 **https://tiera-sable.vercel.app**

AI 모델 순위표는 이미 많다. Tiera가 다른 점은 순위를 **두 개** 매긴다는 것이다.

- **벤치마크 점수** — 시험 성적. 공개 벤치마크 실측치를 정규화한 값
- **커뮤니티 점수** — 써 본 사람들의 체감. 실제 사용자가 남긴 평가

그리고 이 둘이 **어긋나는 지점**을 배지로 드러낸다. 벤치마크는 상위권인데 막상 쓰면
별로인 모델, 점수는 평범한데 유독 평이 좋은 모델 — 그 간극이 Tiera의 존재 이유다.

수록 범위는 개발사 국적 기준 **미국 · 중국 · 한국**이다.

## 화면 읽는 법

### 티어

점수 구간에 따라 네 등급으로 나뉘고, 목록이 티어별로 끊어져서 보인다.

| 티어 | 점수 |
|---|---|
| **PRISM** | 90 이상 |
| **GOLD** | 80 – 89.9 |
| **SILVER** | 65 – 79.9 |
| **BRONZE** | 65 미만 |

### 점수 링

모델 이름 왼쪽의 원이 점수다. 원이 채워진 만큼이 점수이고, 색은 티어를 따른다.

**점선으로 된 링**은 표본이 부족하다는 뜻이다. 평가가 30건 미만이면 `평가 중`,
30건 이상이면 `공인`으로 표시된다. 평가 몇 건으로 1등이 정해지지 않도록 점수 자체에도
보정이 들어간다 — 표본이 적을수록 전체 평균 쪽으로 끌어당긴다.

### 괴리 배지

| 배지 | 뜻 |
|---|---|
| **체감 우위** | 벤치마크 순위보다 커뮤니티 평가가 높은 모델 |
| **스펙 우위** | 벤치마크 순위는 높지만 체감 평가는 아쉬운 모델 |
| **일치** | 두 순위가 비슷한 모델 |

점수 차가 아니라 **순위 차**로 판정한다. 점수 차로 하면 척도가 다른 두 값을 빼는 셈이라
숫자가 커도 의미가 없다.

### 순위 변동

## 쓰는 법

**점수 종류 전환** — 상단 우측 토글로 `커뮤니티 평가` ↔ `벤치마크`를 바꾼다.
같은 모델 집합의 순위가 어떻게 뒤집히는지 보는 게 이 사이트의 핵심이다.

**카테고리** — 종합 · 코딩 · 글쓰기 · 추론 · 멀티모달. 코딩만 잘하는 모델과
글쓰기만 잘하는 모델이 갈린다.

**국가 필터** — 미국 · 중국 · 한국. 필터를 걸어도 **전체 기준 순위 번호를 유지한다.**
1, 2, 3으로 다시 매기지 않는다. "한국 모델 중 1등"이 아니라 "전체에서 몇 등인지"가
알고 싶은 정보이기 때문이다.

**검색** — 모델명과 개발사명으로 찾는다.

**비교** — 각 행의 체크박스로 최대 3개까지 고르면 하단에 비교 트레이가 뜬다.
점수 · 스펙 · 가격 · 벤치마크 원본값을 나란히 놓고 본다.

**모델 상세** — 이름을 누르면 들어간다. 두 점수를 나란히 보여주고, 카테고리별
분해 점수, 컨텍스트 길이 · 가격 같은 스펙, 그리고 벤치마크 원본 수치까지 확인할 수 있다.

**화면 테마** — 상단의 아이콘으로 라이트 / 다크 / 시스템을 고른다.

## 평가 남기기

1. 우상단 **로그인** → GitHub 계정으로 인증
2. 모델 상세 페이지에서 **평가 남기기**
3. 코딩 · 글쓰기 · 추론 · 멀티모달을 각각 별점으로, 한 줄 코멘트는 선택

규칙은 하나다. **모델 하나당 한 사람이 한 번.** 남긴 평가는 언제든 수정하거나
지울 수 있고, 수정하면 점수가 곧바로 다시 계산된다.

**익명으로 남기기**를 체크하면 목록에 이름 대신 `익명`으로 표시된다.
로그인 자체를 건너뛰는 익명은 아니다 — 그렇게 하면 한 사람이 몇 번이든 점수를
밀어 넣을 수 있어서 점수가 의미를 잃는다. 서버는 작성자를 계속 알고 있고,
그래서 1인 1회 규칙과 수정·삭제 권한이 그대로 유지된다. 익명 처리는 화면이 아니라
DB 조회 단계에서 하기 때문에 응답 데이터에도 이름이 실리지 않는다.

## 데이터

**벤치마크 데이터 제공: [Artificial Analysis](https://artificialanalysis.ai)**

벤치마크 점수는 Artificial Analysis에서 매일 자동으로 받아온다.
이 API가 주지 않는 항목(글쓰기 · 멀티모달 등)은 **비워 둔다.** 없는 값을 0으로 채우면
"실제로 0점"과 구분할 수 없게 되기 때문에, 값이 없는 카테고리는 종합 점수 계산에서
아예 빠진다.

커뮤니티 점수는 이 사이트 사용자가 직접 남긴 평가에서 나온다. 다른 곳의 여론을
긁어오지 않는다.

갱신은 매일 자정(KST)에 자동으로 돈다.

## 알아둘 것

- **재미로 보는 티어표다.** 모델 선택의 유일한 근거로 쓰라고 만든 게 아니다.
  점수 산정 방식 전체는 사이트의 [`/about`](https://tiera-sable.vercel.app/about)에 공개돼 있다.
- **커뮤니티 점수는 이제 막 쌓이기 시작했다.** 평가가 충분히 모이기 전까지는
  `평가 중` 표시가 붙고, 표본이 적은 모델일수록 점수가 보수적으로 잡힌다.
- **벤치마크가 없는 모델도 목록에 있을 수 있다.** 이름은 알려져 있지만 공개된
  측정치가 없는 경우인데, 이런 모델은 점수 대신 "데이터 없음"이 표시된다.
